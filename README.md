# workout-tracker
A workout &amp; habit tracker with database-backed login, sessions, and full CRUD — built to actually keep me consistent.
Reps & Habits is a personal workout and habit tracker. Users log in, log workouts and daily habits, and view their progress on a private dashboard. The app uses a real database, persistent login sessions, and full CRUD (create, update, delete) on workout and habit entries — with pages like the dashboard and history locked behind authentication.
